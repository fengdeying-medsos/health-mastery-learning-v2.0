# Lesson design guide

## A useful teaching sequence

1. Start with a one-paragraph plain-language overview.
2. Define essential terms.
3. Explain the process in numbered causal steps.
4. Use a concrete example.
5. Add a diagram, table, or analogy only if it clarifies the model.
6. State limitations and uncertainty.
7. Correct common misconceptions.
8. Ask the learner to retrieve or apply the idea.

## Visual selection

- Anatomy: labeled structure map.
- Sequence: flowchart.
- Mechanism: causal chain.
- Regulation: feedback-loop diagram.
- Comparison: table or side-by-side model.
- Change over time: timeline.
- Whole-topic overview: concept map.

## Analogies

An analogy should illuminate one relationship, not replace the biological explanation. Explicitly state where the analogy breaks down.

## Accessibility

Use short paragraphs, explain abbreviations, and introduce only the technical vocabulary needed for the current lesson.
